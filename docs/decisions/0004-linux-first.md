# 最初の OS は Linux にする

日付は 2026-11-15 です。決定者は Hayato です。状態は採用です。この決定は [最初の OS は macOS にする](0002-macos-first.md) を置き換えます。

最初に動かす OS は Linux です。対象は、クラウドエージェントが使う Linux の VM です。次は macOS で、 Windows はその後です。 Windows を動かす作業は、 `docs/board.md` の TODO にあります。

## 理由

クラウドエージェントは、 Linux の VM 上で、人の操作なしにビルド、起動、録画、計測まで進められます。 macOS を先にすると、 Mac の実機に人が関わる必要があり、自走できません。

Linux の GPUI には、コピーなしで描画を取り込む公式の経路がありません。最初の表示は、 CPU で画素をコピーする方式です。その性能は、起動時間と描画の fps の計測で確かめます。
