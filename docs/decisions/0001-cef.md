# CEF をページの中身にする

日付は 2026-11-15 です。決定者は Hayato です。状態は採用です。

susie のページは Chromium が描きます。組み込みは、 CEF を `cef-rs` の offscreen rendering 経由で行います。

## 理由

1 つ目は、 macOS と Linux と Windows のすべてに、画面の外で描画する公式の経路があることです。 2 つ目は、実在するサイトとの互換性が最も高いことです。次点は Servo です。

Linux での最初の表示は、 CPU で画素をコピーする方式です。 GPUI の Linux には、コピーなしで描画を取り込む公式の経路がないためです。最初の OS を macOS にした記録は [最初の OS は macOS にする](0002-macos-first.md) です。
