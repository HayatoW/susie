# リポジトリは GitHub の公開リポジトリに置く

日付は 2026-11-15 です。決定者は Hayato です。状態は採用です。この決定は [リポジトリは Cursor Origin に置く](0003-cursor-origin.md) を置き換えます。

susie のリポジトリは、 GitHub の公開リポジトリ [HayatoW/susie](https://github.com/HayatoW/susie) です。このリポジトリが、コードとドキュメントの唯一の置き場所です。ソースコードは公開します。アプリの配布はしません。

## 理由

ソースコードが見えても問題ありません。公開リポジトリにすると、 GitHub Actions の CI 、 PR ごとの Devin Review 、 DeepWiki による解説が使えます。
