# 起動時間と描画の fps は S04 で計る

日付は 2026-11-16 です。決定者は Hayato です。状態は採用です。

起動時間と描画の fps は、 S04 で計ります。起動時間と描画 fps を記録する S01 は、ボードから外します。タスク番号は振り直しません。 S01 の PR [#2](https://github.com/HayatoW/susie/pull/2) と [#3](https://github.com/HayatoW/susie/pull/3) は閉じます。

## 理由

S01 は、計測する相手のウィンドウとフレームがまだ無い段階で、計測器だけを作るタスクでした。残る証拠は、テストが渡した作り物の値です。 Hayato はその値を見ても、起動時間と fps をレビューで判断できません。

S04 は、 S03 のフレームを S02 のウィンドウに表示します。ウィンドウとフレームがあるので、プロセスを実際に起動して計れます。
