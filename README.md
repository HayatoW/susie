# susie

susie は、 GPUI で作る Web ブラウザです。

今のアプリは、 Linux で、起動時の引数の URL を GPUI のウィンドウに表示します。引数がないときは、フィクスチャのページを開きます。ウィンドウの上に URL の入力欄が 1 つあります。その欄に URL を打って Enter で、そのページを開きます。 Alt+← で戻り、 Alt+→ で進み、 Ctrl+R で開いているページを読み直します。戻れないときと進めないときは、ページは変わりません。 Ctrl+L で入力欄へ移り、開いている URL を選びます。入力欄をクリックしたときと同じです。戻る、進む、再読み込みのボタンはありません。入力欄とページのどちらに文字が入るかは、クリックした場所で決まります。画素は CPU でコピーします。1 回の起動で、スクロールとクリックと、確定した文字をそのページへ届けます。その起動の `startup_ms` と `fps` は、 `docs/evidence/metrics.jsonl` に残ります。ページへ渡した最初の左クリックの遅れは、同じファイルに `input_ms` として残ります。
