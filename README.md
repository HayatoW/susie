# susie

susie は、 GPUI で作る Web ブラウザです。

名前は、すべてのスコティッシュフォールドの祖先である猫の Susie から取りました。 Susie は 1961 年に、スコットランドの Coupar Angus 近くの農場で見つかった白い猫です。

今のアプリは、 GPUI で空のウィンドウを 1 つ開くだけです。

- タスクは [ボード](docs/board.md) です。
- 決めたことは [決定記録](docs/decisions/) です。
- エージェントのルールは [AGENTS.md](AGENTS.md) です。
